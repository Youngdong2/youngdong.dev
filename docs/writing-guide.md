# 글쓰기 가이드

기술 글은 토스 기술 블로그 구조를 따름. 회고·메모는 자유 형식.

## 기술 글 뼈대
1. 구체적 장면이나 질문으로 시작 (제목은 질문·역설도 좋음)
2. 기존 방식이 왜 안 됐나
3. 문제 재정의 — 글 전체를 관통하는 한 문장
4. 고려한 선택지와 고르지 않은 이유
5. 해결 구조 (그림·표)
6. 전후 수치 + 측정 조건
7. 한계와 다음 단계
8. 일반화된 교훈

## 발행 전 체크리스트
- [ ] 한 문장으로 요약되는가
- [ ] 수치마다 측정 조건(기간, 표본, 환경)이 있는가
- [ ] 예시 값은 예시라고 밝혔는가
- [ ] 회사 내부 정보 공개 범위를 확인했는가
- [ ] description과 aiSummary를 채웠는가
- [ ] draft: false로 바꿨는가
